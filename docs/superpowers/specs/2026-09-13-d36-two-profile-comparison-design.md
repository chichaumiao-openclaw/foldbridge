# D3.6 两条 Profile 对齐比较：最小设计

## 状态与目标

2026-09-13：用户已选择先实现最小并排比较方案。本文件固定实现边界，待书面规格确认后编写实现计划；本文件不代表功能已实现或上线。

让用户在同一 PDB × chain 的共同残基坐标上，同时查看当前 Profile 和另一条已发布 Profile。第一版回答“这些位置分别观察到什么信号”，不自动判断一致性、显著性或结构变化原因。

## 范围与不做事项

- 只支持普通一维 Profile 模式，最多两条。E/F 二维矩阵模式不增加比较控件，也不改变 D3.4 下载。
- 只从当前 Case 生产 profile index 中选择；严格保持链 ID 大小写。两条必须属于同一 render strand，并与当前残基坐标及 strand 长度一致。
- 不新增后端、统计依赖、数据转换、原始 RDAT 请求、跨链对齐或 Case 数据重建。
- 不做差值、相关系数、散点图、显著性检验、实验分组、额外导出或两个结构查看器。
- 仅提供数据覆盖计数，不用它代替差异统计。接口中没有的探针、条件、重复信息不从文件名猜测，也不推断原始实验缺少这些信息。

## 交互

1. 当前主 Profile 选择器和行为保持不变。在其附近添加 `Compare with` 选择器，默认 `None`，不自动选择第二条。
2. 选择器列出相同 strand 的已发布 Profile，排除当前主 Profile，支持按现有公开标签或完整 Profile ID 搜索，沿用现有单 Profile 选择器的模式，不引入新的筛选系统。
3. 当前 Technique 筛选仍只执行现有功能，不自动切换或清空比较对象；比较选择器的候选范围不依赖该筛选结果。
4. 选择第二条后，在现有 1D 主反应性行下方添加第二行；这里的“并排”指上下对齐的两行，不是左右分屏。两行使用同一 SVG 残基横坐标和同一滚动容器，因此滚动天然同步，窄屏也不新增页面级横向溢出。
5. 两条标注为 `Primary` 和 `Comparison`，附近分别显示 Profile ID、已有方法标签和显示尺度。长 ID 可换行或通过可访问的完整文本查看，不扩大轨道宽度。
6. 新增行的悬停或键盘聚焦只显示该行的位点、保存值、显示值和缺失状态，不切换主 Profile 或为 2D/3D 着色。主轨道原有选择和结构联动保持不变；2D/3D 与 inspector 始终使用主 Profile。
7. 选择 `None` 即移除第二行。只有一条可选 Profile 时，禁用比较选择器并提示无其他可比较 Profile；零 Profile 维持现有空态。
8. 主 Profile 切换后，若比较对象仍是不同的同 strand Profile，保留并更新比较；若与新主 Profile 相同或不再符合坐标条件，则显式清空并提示原因，不自动替换成另一条。切换 Case/chain 时清空比较状态。

## 显示与科学边界

复用现有 `normalizeReactivityProfile` 与 C 类三状态渲染：缺失、实测有限非正值、正值。第二条使用自己的现有 P95 显示尺度，不能用主 Profile 的尺度去重新标定比较 Profile。

两行均明确显示各自 P95 上限，并共用提示：`Each profile is scaled independently for display. Compare positional patterns, not absolute signal magnitudes.` 保存值保持不变；此处“保存值”指网站 shard 中的输入值，不宣称它是未经实验处理的原始测量值。全缺失或没有正值时保留现有三状态，不制造数值信号或有效缩放上限。

允许跨方法查看，但不宣称不同方法的数值、颜色或强弱阈值可直接等同；不做跨技术统一归一化。

覆盖摘要固定以完整共同 strand 的 L 个位置为分母，显示主 Profile 有限值数 A/L、比较 Profile 有限值数 B/L、共同有限值数 shared/L。有限的零值和负值均计入，NaN/Infinity 不计入；不声称这些位置全部已在三维结构中解析。`shared=0` 时明确提示没有共同有效位置，仍允许查看各自覆盖。

## 数据流与错误处理

- 复用 `loadShard` 的已解压缓存和 `profileValues` 的单行读取；同 shard 不重复加载，不预加载每个候选的整条数据。
- 比较模型仅持有当前第二条的 ID、加载状态、保存值、独立显示结果及覆盖摘要；主状态 `lastRender` 不被比较操作覆盖。
- 加载前验证选择来自当前 index；加载后验证 strand 身份、行索引边界、数据长度及 shard 元数据。不截断、补零或悄悄换用其他 Profile。
- 请求以当前 Case/chain、主 Profile、比较 Profile 及递增请求标识绑定。快速切换、取消或退出页面后，过期响应不得重绘当前比较。复用缓存不豁免身份验证。
- 加载过程中不把上一条的轨道或统计显示为新选择。失败时清除失效比较显示并给出可读错误；主 Profile、现有结构及选择状态保持可用。不自动重试或 fallback。
